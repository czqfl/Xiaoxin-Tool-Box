# 小心工具箱 · Xiaoxin Tool Box

> 一款常驻 Windows 桌面的轻量级快捷工具集：**悬浮工具栏 + 剪贴板 + 截图贴图 + 划词翻译 + 账号密码 + 便签**……
> 基于 **Tauri v2 + React 18 + TypeScript + Rust** 构建，安装包小、启动快、内存占用低，不依赖浏览器运行时。
> 所有数据仅存本机，不上云。

---

## 一、功能总览

| 模块 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 悬浮工具栏 | — | 桌面常驻入口，贴边自动收起、靠近自动弹出、磁吸图标、点击穿透 |
| 剪贴板历史 | `Alt+C` | 文本/图片/文件历史记录，点击回贴；支持顺序粘贴队列 |
| 截图 | `Ctrl+Alt+A` | 冻结屏幕全屏选区：智能窗口识别、标注、马赛克、OCR、取色、放大镜 |
| 屏幕取色 | `Alt+D` | 全屏十字线取色模式（不进截图），C 复制 / Shift 切 RGB·HEX |
| 贴图（钉图） | `Ctrl+Alt+P` | 把截图或剪贴板内容钉在桌面：缩放/透明度/旋转/鼠标穿透/整批唤回 |
| 文件夹 | `Alt+F` | 常用目录一键打开，支持直达终端 |
| 账号密码 | `Alt+A` | 本地保存的账号密码速查面板 |
| 划词翻译 | `Alt+S` | 选中文字即弹翻译窗，支持剪贴板兜底 |
| 端口工具 | `Alt+P` | 端口占用查询 / 一键结束进程 |
| 快速文件 | `Alt+Q` | 分三页：常用文件（统一位置新建/管理）、最近打开（按时间或次数）、全盘搜索（本机文件名秒查） |
| 常用语速贴 | `Alt+K` | 快捷短语一键粘贴 |

> 所有快捷键均可在「设置 → 快捷键」中自定义；各功能可在「功能开关」页整体停用。

## 二、核心用法

### 1. 悬浮工具栏
- 启动后出现在主显示器右下角，常驻系统托盘；
- 拖到屏幕边缘可自动收起成一条细边，鼠标靠近即滑回；
- 光标不在其上时不拦截任何桌面点击（点击穿透）。

### 2. 截图（Snipaste 式工作流）
1. 按快捷键呼出 → 整屏冻结 + 自动压暗，智能识别鼠标处窗口/UI 元素并高亮；
2. 左键拖拽自定义区域，或左键单击采纳识别的窗口；
3. 选区内可用工具条进行标注：矩形、椭圆、直线、箭头、画笔、文字、马赛克、序号等；
4. 输出方式：
   - `Enter` / 工具条按钮 —— 复制到剪贴板；
   - 贴图按钮 / 用户配置的「贴图热键」（如 F8）—— 直接钉到屏幕原位；
   - 另存为按钮 —— 系统对话框保存 PNG；
5. 实用键位：
   - `<` / `>`：翻看历史截屏（换冻结帧重新框选），`H` 打开历史缩略图列表，
     点击任意一帧会还原该帧画面 **以及当时框选的范围**；
   - 放大镜实时显示坐标与颜色，`C` 复制颜色、`Shift` 切 RGB/HEX；
   - 框选文字后点 OCR 按钮（或工具条）→ 内置 PP-OCR（ONNX）模型离线识别，中英混排/小字号/深色底都能认，可划选复制/直接翻译；模型档位可在「设置 → 截图贴图」切换；
   - `Esc` 退出。

### 3. 贴图（Pin）
- 来源：截图输出、剪贴板图片、富文本/纯文本（复制后在目标位置按贴图热键）；
- 贴图窗交互：
  - 滚轮缩放；按住左键 + 滚轮 或 Ctrl+滚轮调透明度（5%~100%）；
  - 左键拖动移动；双击或 `Delete` 彻底删除；`Esc` 仅隐藏；
  - `Ctrl+C` 复制这张贴图的原图到剪贴板；
  - 右键菜单：开启鼠标穿透、关闭阴影、隐藏/关闭等；
- `Ctrl+Alt+P` 在「显示最近一张贴图」与「全部隐藏」间切换；剪贴板有新内容时直接贴出新贴图。

### 4. 剪贴板历史
- 后台自动记录复制的文本 / 图片 / 文件，面板内点击回贴；
- 支持收藏置顶、容量上限配置；图片存原图 + 面板缩略图；
- 「顺序粘贴」模式：把多条记录排成队列，连续粘贴依次出队。

### 5. 其余模块
- **文件夹**：常用目录列表，一键打开资源管理器或终端；
- **账号密码**：本地加密存储，速查 + 一键复制，绝不联网；
- **划词翻译**：选中文字按热键弹出译文卡片；
- **端口工具**：输入端口查占用进程，一键结束；
- **快速文件**：预置 Markdown / 待办等类型模板，一键在指定目录新建文件；另有「最近打开」（按次数或时间排序）与「全盘搜索」（本机文件名秒查，索引只存名字与目录、纯本地）；
- **常用语速贴**：维护短语列表，点击即粘贴；
- **便签**：桌面便签，支持背景图与毛玻璃，关闭动画可选粒子消散 / 吸入 / 侵蚀。

## 三、安装与运行

### 安装版 / 便携版
仓库根目录的发布产物：

| 文件 | 形态 | 说明 |
| --- | --- | --- |
| `小心工具箱-安装版-vX.Y.Z.exe` | NSIS 安装包 | 双击安装，含开始菜单与卸载项 |
| `小心工具箱-便携版-vX.Y.Z.zip` | 绿色便携版 | 解压即用，数据存 exe 同级 `data\`，整体拷贝即可迁移 |

运行要求：Windows 10/11（WebView2 运行时由系统提供）。启动后程序常驻系统托盘。

### 开发运行
```bash
npm install
npm run dev:app     # 启动 Tauri 开发模式（vite + rust）
npm run tauri build # 构建发布产物
npm run pack        # 调用 scripts/build-release.ps1 出安装包 + 便携包
```

## 四、架构

### 总体
```
┌───────────────────────────────────────────────┐
│  WebView2 多窗口前端（React 18 + TS + Vite） │
│  toolbar / panels / shot-overlay / pins / …   │
└───────────────△───────────────────────────────┘
        Tauri IPC │        ▲ 自定义协议直出字节
┌───────────────────┴───────────────────────────┐
│  Rust 后端（tauri v2, tokio, Win32）          │
│  截图引擎 · 贴图管理 · 剪贴板监听 · 热键钩子 │
└───────────────────────────────────────────────┘
```

每个功能一个独立无边框窗口（`src-tauri/tauri.conf.json` 预声明 + 动态创建），
前端按窗口 label 单入口路由（`src/App.tsx`），共享一套主题令牌与配置存储。

### 前端结构（src/）
```
src/
├── App.tsx              # 按窗口 label 路由到各模块根组件
├── core/
│   ├── tauri.ts         # 全部 IPC 封装（invoke / 二进制直传 / 协议 URL）
│   ├── events.ts        # 事件名约定与订阅封装
│   └── theme.ts         # 主题应用（多套配色，跟随系统）
├── stores/              # zustand：configStore 等
├── modules/             # 各功能模块（组件 + 模块级 css）
│   ├── toolbar/         # 悬浮工具栏
│   ├── clipboard/       # 剪贴板面板（含顺序粘贴队列）
│   ├── screenshot/      # 截图遮罩层（选区/标注/放大镜/OCR/历史 UI）
│   ├── pin/             # 贴图窗（常规窗 + staging 复用窗两种形态）
│   └── folder|credential|translate|port|quickfiles|snippets/
└── settings/            # 设置中心各页
```

### 后端结构（src-tauri/src/）
| 模块 | 职责 |
| --- | --- |
| `screenshot.rs` | 截图主流程：多屏冻结帧、原生拖拽直绘、智能窗口/UIA 识别、输出（复制/另存/贴图）、截图历史、BMP/PNG 字节协议直出 |
| `pin.rs` | 贴图生命周期：入库落盘、staging 复用窗秒显、缩放/穿透/批量显隐、持久化恢复 |
| `clipboard.rs` | 剪贴板监听线程、条目构建（文本/图片/文件）、缩略图、写回粘贴 |
| `keyhook.rs` | 低级键盘钩子：纯 Alt 组合热键吞键、顺序粘贴队列拦截 |
| `shortcut.rs` | RegisterHotKey 热键注册/冲突检测/重注册 |
| `panel.rs` / `tray.rs` | 面板窗口显隐编排 / 托盘菜单 |
| `ocr.rs` | PP-OCR 离线文字识别（rapidocr-core + ONNX Runtime）、模型档位管理与词框推导 |
| `acrylic.rs` | 亚克力/毛玻璃与前台抢焦点的 Win32 实现 |
| `folder.rs` `quickfiles.rs` `snippets.rs` `credentials.rs` `translate.rs` `port.rs` | 各功能业务 |
| `fsindex.rs` | 全盘文件名索引：复用 ripgrep 的 `ignore` 并行遍历 + 紧凑存储 + 零分配子串打分搜索 |
| `recentfiles.rs` | 最近打开文件（打开动作在 `quickfiles_open` 单点打点，按时间/次数排序） |
| `storage.rs` `config.rs` | 数据目录、JSON 持久化、配置模型 |

### 关键性能机制
- **帧直出协议**：冻结帧/贴图图/历史档经 `http://screenshot.localhost` 由
  WebView2 原生网络栈读盘直传，绕开 base64 与 JSON 序列化；
- **贴图最快路径**：选区原始像素零拷贝直传 Rust → 包零压缩 BMP 落盘 →
  WebView2 解码 BMP 近乎 memcpy，全程无 PNG 编解码；
- **staging 复用窗**：预建隐藏贴图窗待命，新贴图免建窗秒显（含 rAF 节流规避）；
- **原生直绘拖拽**：框选/缩放过程由 Rust 线程轮询光标直绘冻结层，零 IPC；
- **历史翻页缓存**：历史档解码结果常驻缓存 + 相邻帧后台预取，`<`/`>` 切换近乎瞬时；
- **轻量换帧**：历史切换只替换冻结帧，不整页重载遮罩 UI；
- **OCR 会话常驻**：ONNX session 启动后台预热并缓存复用（切档位才重建），
  推理线程上限 4，避免贴图批量识别把 CPU 吃满拖慢界面。

### 数据存储（便携版位于 exe 同级 `data\`）
```
data/
├── config.json             # 全局配置
├── clipboard_history.json  # 剪贴板历史索引
├── images/                 # 剪贴板图片原件 + 缩略图
├── pins.json  pins/        # 贴图清单与图片文件
├── shot_history/           # 截图历史档（png + 选区 sidecar）
├── models/                 # 下载的高精度 OCR 模型（内置 tiny 档随安装包放在 exe 同级）
├── recent_files.json       # 最近打开文件（次数 + 最近打开时间）
├── file_index.bin          # 全盘文件名索引缓存（约 60MB / 百万条目，可删，删后需重建）
└── folders.json 等         # 各功能数据
```
迁移 = 整体拷贝 `data\` 目录。卸载不会删除便携版数据。

## 五、注意事项

- 账号密码等敏感数据仅存本机，请自行备份；
- 若快捷键被其他软件占用，保存时会提示冲突；
- 高分屏（125% / 150% 缩放）与多显示器已适配，坐标统一按物理像素处理；
- 反馈问题请附上 `data\diag.log` 诊断日志。
