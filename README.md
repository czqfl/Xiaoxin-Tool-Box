# 小心工具箱 · Xiaoxin Tool Box

> 一款常驻 Windows 桌面的轻量级效率工具集：**悬浮工具栏 + 剪贴板 + 截图贴图 + 录屏 + 划词翻译 + 桌面便签**……
> 基于 **Tauri 2 + React 18 + TypeScript + Rust（Win32）** 构建，安装包小、启动快、不依赖浏览器运行时。
> **所有数据仅存本机，功能全程离线可用（OCR 离线、翻译接口自填除外）。**

| | |
| --- | --- |
| 平台 | Windows 10 / 11（WebView2 由系统提供） |
| 版本 | 1.0.1 |
| 技术栈 | Tauri 2 · React 18 · TypeScript · Rust 2021 · Vite 6 |
| 规模 | 196 个 IPC 命令 · 31 个后端模块 · 14 个前端模块 · 13 个预声明窗口 + 若干动态窗口 |

## 二、核心用法

### 1. 悬浮工具栏
- 启动后常驻主显示器边缘（默认右侧竖条），同时驻留系统托盘；
- 拖到屏幕边缘自动收起成一条细边，鼠标靠近即滑回；
- 光标不在其上时不拦截任何桌面点击（点击穿透）；
- 默认显示剪贴板、文件夹、账号密码、翻译、端口、设置六个入口，可增删排序。

### 2. 截图（Snipaste 式工作流）
1. 按快捷键呼出 → 整屏冻结并压暗，自动识别鼠标处的窗口 / UI 元素并高亮；
2. 左键拖拽自定义区域，或单击直接采纳识别到的窗口；
3. 选区内用工具条标注：矩形、椭圆、直线、箭头、画笔、文字、马赛克、序号等；
4. 输出方式：复制到剪贴板 / 直接钉成贴图 / 另存为 PNG；
5. 实用键位：
   - `<` `>` 翻看历史截屏（换冻结帧重新框选），`H` 打开历史缩略图列表，点击可还原该帧**以及当时的框选范围**；
   - 放大镜实时显示坐标与颜色，`C` 复制颜色、`Shift` 切 RGB/HEX；
   - 框选文字后点 OCR → 离线识别，可划选复制或直接翻译；
   - `Esc` 退出。

### 3. 贴图（Pin）
- 来源：截图输出、剪贴板图片或文本；
- 交互：滚轮缩放；`Ctrl`+滚轮 或 按住左键+滚轮 调透明度（5%–100%）；左键拖动移动；双击或 `Delete` 删除；`Esc` 仅隐藏；`Ctrl+C` 复制原图；
- 右键菜单：鼠标穿透、阴影开关、另存、OCR 等；
- `Ctrl+Alt+P` 在「显示最近一张贴图」与「全部隐藏」间切换，`Ctrl+Alt+K` 关闭全部。

### 4. 剪贴板历史
- 后台自动记录复制的文本 / 图片 / 文件，面板内点击即回贴；
- 收藏与置顶、容量上限配置、图片存原图 + 面板缩略图；
- **顺序粘贴模式**（FIFO / LIFO）：把多条记录排成队列，连续粘贴依次出队，支持队列内移动、重排、回滚与消费。

### 5. 屏幕录制
- 选区后开始录制，浮出控制条（暂停 / 续录 / 停止 / 取消），结束后可直达保存目录；
- 输出格式：MP4（Media Foundation H.264 编码）或 GIF（增量编码，内存占用恒定）；
- 分辨率：原始 / 1080 / 720 / 360；帧率 5–60（默认 12）；画质 high / normal / fast；
- 音频：可选麦克风与系统声音（WASAPI 环回），支持静音与音量调节。

### 6. 滚动截图
- 框选区域后自动滚动并逐屏拼接成长图，可随时停止或取消；
- 滚动速度可调，结果支持另存为图片或转成贴图。

### 7. 文件夹与 Git
- 常用目录卡片式管理：置顶、排序、颜色标记、一键打开资源管理器；
- 右键直达终端，或直达已探测到的编辑器（VS Code 等，可手动指定路径）；
- Git 能力：
  - 卡片显示当前分支（读 `.git/HEAD`，毫秒级；非仓库不显示）；
  - 多条 Git 命令按顺序执行，输出在**独立结果窗口**里逐行实时上屏（`add` → `commit` → `push` 一条龙的每步输出都看得见），窗口智能停靠在面板左/右侧；
  - 命令经 PowerShell 执行，继承用户 `$PROFILE` 里的代理 / SSH 等环境配置，手动能连这里就能连。

### 8. 快速文件
- **常用文件**：按预设类型（Markdown、待办等）在统一目录一键新建，支持打开、在资源管理器中显示、删除；
- **最近打开**：自动记录本机最近打开的文件，可按时间或打开次数排序（打开动作单点打点；文件被移走后仍显示它是哪个文件）；
- **全盘搜索**：本机文件名秒级检索（索引只存文件名与目录，纯本地），支持索引重建与取消；
- **应用启动**：列出已安装应用并一键拉起。

### 9. 桌面便签
- 每条便签一个独立窗口：Markdown 正文与自定义样式、优先级标记；
- 外观：背景图或取桌面壁纸、毛玻璃/亚克力、窗口置顶；
- 窗口动作：最小化到任务栏或系统托盘、关闭（带粒子消散动效）、历史便签回看；
- 内容工具：LLM 格式化、截取屏幕区域作为便签内容；
- 便签可在设置中单独配置存放目录与快捷键。

### 10. 其余面板
- **账号密码**：本地保存，速查 + 一键复制，密码默认遮罩（可切换显示）；
- **划词翻译**：选中文字按热键弹出译文卡，支持多行与剪贴板兜底，上次结果可复用；
- **端口工具**：输入端口查占用进程，或按端口/进程名搜索，一键结束进程；
- **常用语速贴**：短语增删改，点击即粘贴到当前输入焦点。

## 三、安装与运行

### 发布产物
| 文件 | 形态 | 说明 |
| --- | --- | --- |
| `小心工具箱-安装版-vX.Y.Z.exe` | NSIS 安装包 | 双击安装，含开始菜单与卸载项 |
| `小心工具箱-便携版-vX.Y.Z.zip` | 绿色便携版 | 解压即用，数据存 exe 同级 `data\`，整体拷贝即可迁移 |

运行要求：Windows 10/11（WebView2 运行时由系统提供）。启动后程序常驻系统托盘。

### 开发运行
```bash
npm install
npm run dev:app      # 启动 Tauri 开发模式（vite dev 端口 1423 + Rust 调试构建）
npm run tauri build  # 构建发布产物
npm run pack         # 调用 scripts/build-release.ps1，产出安装包 + 便携包
```

> Rust 侧改动需重启 `npm run dev:app` 重新编译；前端改动由 vite 热更新即时生效。

| 模块 | 职责 |
| --- | --- |

### 关键性能机制
- **帧直出协议**：冻结帧 / 贴图图 / 历史档经 `http://screenshot.localhost` 由 WebView2 原生网络栈读盘直传，绕开 base64 与 JSON 序列化；
- **贴图最快路径**：选区原始像素零拷贝直传 Rust → 零压缩 BMP 落盘 → WebView2 解码 BMP 近乎 memcpy，全程无 PNG 编解码；
- **staging 复用窗**：预建隐藏贴图窗待命，新贴图免建窗秒显；
- **原生直绘拖拽**：框选/缩放过程由 Rust 线程轮询光标直绘冻结层，零 IPC；
- **历史翻页缓存**：历史档解码结果常驻缓存 + 相邻帧后台预取，切换近乎瞬时；
- **OCR 会话常驻**：ONNX session 后台预热并复用（换档位才重建），推理线程上限 4，避免批量识别拖慢界面；
- **GIF 增量编码**：录屏 GIF 逐帧写入文件流，内存占用恒定；
- **开发构建优化**：`[profile.dev.package."*"]` 对第三方依赖开 `opt-level = 2`，否则 image/gif 编码慢一个数量级（录屏会从 20fps 掉到 ~1fps）。

### 主题
7 套配色，默认跟随系统：`System` / `Light` / `Dark` / `Mint`（浅青）/ `Skyblue`（浅蓝）/ `Red` / `Orange`。
全部走 CSS 变量令牌（`--c-*`、`--tool-*`、`--font-*`），各面板与便签共享同一套视觉语言。

## 五、数据存储（便携版位于 exe 同级 `data\`）
```
data/
├── config.json             # 全局配置（快捷键、主题、各模块开关与参数），支持导出/导入备份
├── clipboard_history.json  # 剪贴板历史索引

├── pins.json  pins/        # 贴图清单与图片文件
├── shot_history/           # 截图历史档（png + 选区 sidecar）
├── notes/                  # 桌面便签内容与背景图
├── models/                 # 下载的高精度 OCR 模型（tiny 档随安装包放在 exe 同级）
├── recent_files.json       # 最近打开文件（次数 + 最近打开时间）
├── file_index.bin          # 全盘文件名索引缓存（约 60MB / 百万条目，可删，删后需重建）

└── folders.json 等         # 各功能数据
```
迁移 = 整体拷贝 `data\` 目录；卸载不会删除便携版数据。

## 六、注意事项

- 账号密码等敏感数据仅存本机，请自行备份；
- 快捷键若被其他软件占用，保存时会提示冲突；纯 Alt 组合由键盘钩子主动吞键，不会泄漏进编辑器替换选中文字；
- 高分屏（125% / 150% 缩放）与多显示器已适配，坐标统一按物理像素处理；
- 全盘文件名索引首次构建需遍历磁盘，可在「设置 → 快速文件」查看进度或取消；
