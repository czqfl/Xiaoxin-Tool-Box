# 小心工具箱 · 应用功能说明

> 一款常驻 Windows 桌面的轻量级快捷工具集。基于 **Tauri v2 + React + TypeScript + Rust** 构建，体积小、启动快、不依赖浏览器运行时。
> 当前版本：**v1.0.1**（本次更新重点修复高分屏下「悬浮工具栏贴边收起」消失的问题）。

---

## 一、它能帮你做什么

小心工具箱把日常高频的零散操作收敛到**一个悬浮在桌面边缘的工具栏**里：剪贴板历史、常用文件夹、账号密码、划词翻译、端口工具、桌面便签……需要时随手一点即开，用完自动退场，不打扰桌面工作。

| 模块 | 一句话说明 |
| --- | --- |
| 悬浮工具栏 | 桌面常驻入口，可吸附边缘自动收起、光标靠近自动弹出 |
| 剪贴板 | 本地剪贴板历史，随手回贴之前复制过的内容 |
| 文件夹 | 常用目录一键打开，省去层层翻找 |
| 账号密码 | 本地保管的账号/密码速查（数据存本机，不上云） |
| 划词翻译 | 选中文字即弹翻译窗，阅读外文更顺手 |
| 端口工具 | 端口相关的快捷查询/操作 |
| 便签 | 桌面便签，支持背景图、毛玻璃与粒子消散关闭动画 |
| 粒子特效层 | 全屏透明粒子层，承载便签关闭时的消散/吸入等动效 |
| 设置中心 | 主题、开机自启、快捷键、各模块参数统一配置 |

## 二、悬浮工具栏（核心交互）

工具栏是整套工具的「总开关」，设计目标是**既常在手边，又不挡事**：

- **贴边自动收起**：工具栏停靠屏幕边缘后，可自动滑出屏幕、仅留出一条几像素的细边；把鼠标移到该边缘附近即平滑滑回原位（无需精准戳中细边）。
- **启动定位**：每次启动默认出现在**主显示器右下角**，避免「一开软件就找不着」的问题。
- **点击穿透**：光标不在工具栏上时，它不拦截桌面点击；移到上面才恢复可交互，真正做到「隐身待命」。
- **磁吸图标**：鼠标靠近时邻近图标会被轻微吸引、放大，交互更有手感。
- **高分屏适配**：坐标按物理像素处理，在 125% / 150% 等缩放下收起留边、靠近弹出均正常工作（这正是 v1.0.1 修复的内容）。

## 三、各功能模块详解

### 1. 剪贴板（Clipboard）
记录最近复制的文本/内容历史，点击即可回填。支持自定义全局快捷键呼出（如 `Ctrl+Alt+C`），复制频繁的场景下尤为省力。

### 2. 文件夹（Folder）
把常用目录加进快捷列表，一键在资源管理器中打开（如 `Ctrl+Alt+F`）。适合项目多、目录深的用户。

### 3. 账号密码（Credential）
本地存放的账号/密码速查面板（如 `Alt+A`）。数据保存在本机，**不经过任何云端**，适合随手记一些非敏感或你信任本机安全的凭据。

### 4. 划词翻译（Translate）
选中文字后弹出翻译窗口，快速得到译文。翻译面板无边框、置顶、轻量，读文档/网页时随用随走。

### 5. 端口工具（Port）
针对本地端口的快捷工具集（查询/排查等），窗口小巧、置顶显示，便于开发调试时随手调用。

### 6. 便签（Sticky Note）
桌面便签，可：
- 设置**全局默认背景图**或透明/毛玻璃主题；
- 选择关闭动画风格：**粒子消散 / 粒子吸入 / 侵蚀**，并可调节**粒子强度**；
- 绑定专属全局快捷键（呼出 / 全部关闭 / 新建）。

### 7. 粒子特效层（Particles）
一个全屏、透明、置顶、不可聚焦的窗口层，专门承载便签关闭时的粒子动效，让「销毁便签」这件事有视觉反馈而不突兀。

## 四、主题与外观

内置多套配色，深浅主题采用中性石墨灰（深色背景约 `20,20,20` / 侧栏 `31,31,31`），不偏蓝、观感干净：

- 跟随系统
- 浅色
- 浅青（mint）
- 浅蓝（skyblue）
- 红色（red）
- 深色（dark）

设置窗口的原生标题栏颜色会精确跟随当前主题的侧栏色（通过 Windows DWM 实现），深浅切换时整体协调统一。

## 五、快捷键

所有呼出类快捷键均可在「快捷键」设置页自定义（捕获新组合即可，例如 `Ctrl+Alt+C` / `Ctrl+Alt+F` / `Alt+A`）。便签另含「呼出 / 全部关闭 / 新建」三组专属快捷键，改完即时生效。

截图与取色：
- 截图选区阶段自带**屏幕取色**（Snipaste 同款）：放大镜实时显示光标坐标与颜色，按 `C` 复制颜色、按 `Shift` 切换 RGB / HEX 显示格式，复制内容跟随当前格式（`rgb(20,20,20)` / `#141414`）；
- 另有**独立的「屏幕取色」全局热键**（默认 `Alt+D`，可改）：不进截图，呼出后全屏十字线跟随鼠标，面板显示坐标与颜色，`C` 复制、单击复制并退出、`Esc` 收场。

## 六、设置中心

通过工具栏「打开设置」或系统托盘进入，分区清晰：

- **通用**：主题、语言、开机自启、静默启动、面板外观、配置备份等；
- **悬浮工具栏**：启用开关、贴边自动收起等行为；
- **剪贴板 / 文件夹 / 便签 / 翻译**：各模块专属参数；
- **快捷键**：全局热键管理；
- **关于**：版本与信息。

配置默认存于本机（便携版存于 `data\` 目录），迁移方便。

## 七、安装与运行

提供两种分发形态，均在仓库根目录产出（以 v1.0.1 为例）：

| 文件 | 形态 | 适用场景 |
| --- | --- | --- |
| `小心工具箱-安装版-v1.0.1.exe` | NSIS 安装包 | 双击安装到系统，开始菜单/卸载齐全 |
| `小心工具箱-便携版-v1.0.1.zip` | 绿色便携版 | 解压即用，数据存 `exe` 同级 `data\`，可整体拷贝迁移 |

**便携版使用提示：**
1. 解压到任意有读写权限的目录（避免 `C:\Program Files`）；
2. 双击「小心工具箱.exe」运行，程序常驻系统托盘；
3. 所有数据保存在同目录 `data\` 下，整体复制即可完成迁移；
4. 默认快捷键参考：呼出剪贴板 `Alt+C`、文件夹 `Alt+F`（实际以「快捷键」设置页为准，可改）。

**运行要求：** Windows 10/11 桌面环境。安装版会写入开始菜单与卸载项；便携版无需安装。

## 八、版本与更新

- **v1.0.1**（本次）
  - 修复：高分屏（>100% 缩放）下悬浮工具栏「贴边收起」整条飞出屏幕、且靠近边缘不弹出的问题。根因为收起/弹出动画的坐标单位（物理像素）与窗口定位 API（逻辑像素）不匹配导致二次缩放，现已统一为物理像素。
- **v1.0.0**（初始发布）
  - 悬浮工具栏、剪贴板、文件夹、账号密码、划词翻译、端口工具、便签与粒子动效、多主题、全局快捷键、开机自启等基础能力。

## 九、注意事项

- 账号密码等数据**仅存于本机**，请自行做好备份（可用「通用 → 配置备份」）；换机时拷贝 `data\` 或配置目录即可迁移。
- 悬浮工具栏默认开启「贴边自动收起」；若你不喜欢「靠近边缘自动收起」的行为，可在「悬浮工具栏」设置中关闭「靠边自动收起」。
- 若启动后工具栏未出现在右下角，请确认未被其他窗口遮挡，或重启应用；如仍异常，多为多显示器/混合缩放场景，可反馈具体现象以便进一步适配。
