# 2026-08-21 工作日志

## 新增「常用语速贴」面板（commit 6845a5a，不推送）
- 需求来源：主人从候选清单里只选了「常用语速贴」（第一梯队启动器/截图OCR/取色器/文本工具箱均未选）。
- 功能：管理常用话术/文本片段，点击卡片一键粘贴到当前输入框（类 Espanso/快贴轻量版）。
- 粘贴链路（复用剪贴板面板已验证模式）：
  `snippets_paste` → `clipboard::clipboard_copy_text`（写剪贴板+SUPPRESS_WATCH 抑制历史）
  → spawn 延迟 80ms `keyhook::send_ctrl_v()`（带魔数防钩子误吞）→ 前端立即 hideCurrentWindow()
  → 焦点归还用户原窗口 → Ctrl+V 生效。
- 架构（沿用按面板拆模块模式）：
  - `src-tauri/src/snippets.rs`：Snippet{id,title,content,group,created_at,updated_at}，
    每次操作全量读写 data/snippets.json（同 quickfiles 模式，不维护内存 state）；
    命令 snippets_list/create/update/delete/paste；id 用 uuid::Uuid::new_v4()
  - storage.rs AppPaths 加 snippets_file；panel.rs 加 SNIPPETS_PANEL + ALL_PANELS + toggle 映射；
    lib.rs 注册命令 + apply_panel_acrylic 列表；tauri.conf.json 加 snippets-panel（380×560 可缩放）
  - 前端 src/modules/snippets/：SnippetPanel + api + css；App/main 路由；types.ts 加 Snippet、
    ToolKey 加 "snippets"；icons.tsx 加 IconSnippet（闪电）；theme.css 6 主题各加 --tool-snippets（玫粉系）
  - 工具栏 TOOLS 加 snippets；configStore 默认值 + data/config.json 的 toolbar.tools 同步加 "snippets"
    （吸取上次"删便签只动代码、运行时配置残留导致空位"教训，这次主动同步）
- 面板 UX：搜索 + 分组 chips + 卡片 hover 出编辑/删除（删除二次确认 3s）+ 新增/编辑应用内模态；
  Enter 保存、Esc 关闭/关模态；点击卡片=粘贴并关闭。
- 验证：tsc --noEmit 退出码 0；cargo check 退出码 0 无警告。
- 顺带提交工作树遗留的 quickfiles.rs use-after-free 修复（DIB 像素须在 DeleteObject 前拷贝，
  否则读释放内存 STATUS_ACCESS_VIOLATION 崩溃）。
- 经验：新面板接入点清单（可复用）——Rust 模块+storage 路径+panel 常量/映射+lib 命令/acrylic
  列表+tauri.conf 窗口+前端模块+App/main 路由+types+图标+主题变量+工具栏 TOOLS/映射+config 默认
  值+运行时配置同步，共 15 处；漏一处就是"入口点不开/窗口找不到/图标缺失/空位"。
