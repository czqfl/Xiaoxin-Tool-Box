## 浅色主题小字对比度修复（commit 3d287a6，不推送）
- 主人反馈：浅色系主题（light/mint/skyblue/red）下面板上灰色小字看不清。
- 根因：--text-tertiary 太浅——light #97a0ad 对面板背景(rgb 248,249,251)对比度仅 2.5:1
  （WCAG AA 文本需 4.5:1）；secondary 5.7~7.2 也偏弱。
- 修复：按各主题面板背景色（light 248,249,251 / mint 246,251,250 / skyblue 234,243,253 /
  red 252,246,245）精确计算新值，tertiary 提至 5.8~6.8、secondary 提至 7.6~9.3，
  保持 primary>secondary>tertiary 层级。所有 placeholder/描述/空状态均走 token 自动受益。
- 排查确认：无硬编码浅灰文字；opacity 弱化多为禁用态按钮/空状态图标（有意设计，不动）。
- 验证：WCAG 对比度脚本计算（相对亮度公式）确认达标；纯 CSS 改动。
- 经验：浅色主题"小字看不清"首选查 --text-tertiary/--text-secondary 对背景的对比度
  （目标 ≥4.5:1），按背景色逐主题计算而非统一调一个值（各主题底色有色调差）。

## 快速文件毛玻璃化（commit 8a69ff7，不推送）
- 主人反馈：按钮组选中态、新建按钮、卡片右上角类型标签没有"模糊+透明"效果。
- 三处改 backdrop-filter 毛玻璃：

     + inset 描边；图标色改回 accent（玻璃底上白字对比差）。

  才能用 color-mix 做半透明玻璃，内联 background 无法玻璃化。

## 快速文件按钮缩小 + 新建按钮玻璃补全（commit ecea040，不推送）
- 主人反馈：①按钮组按钮太大要缩小；②新建按钮（尤其加号圆片）没有透明+模糊。
- 关键根因：**Chromium 在元素自身有 transform 时跳过 backdrop-filter**——
  qf-new-btn 的 hover translateY(-1px)/active scale 让 blur 不生效，这正是
  "加了 blur 却没有模糊"的原因。移除 transform 动画，仅保留颜色过渡。
- 改动：按钮 28→24px、图标 16→14；新建按钮玻璃底提亮（渐变 20%/hover 34%）；
  加号圆片实色→半透明玻璃(22%+blur10px)+描边+内高光，hover 加深 40%+旋转；
  选中态补顶部内高光（背景无内容时 blur 不可见，靠半透明+高光传达玻璃感）。
- 经验：backdrop-filter 不可见排查顺序：①元素/祖先有无 transform（有则失效）；
  ②背后有无可模糊内容（纯色背景无感）。修 transform 是硬修复，高光是视觉兜底。
