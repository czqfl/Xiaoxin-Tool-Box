## 端口工具：新增「进程路径 + 命令行」反查启动项目（Req H）
- 需求：查询某端口（如 8081）时，能看出占用它的进程是「哪个项目启动的」（例：hussar-front 前端项目）。
- 实现：
  - `src-tauri/src/port.rs`：`PortProcess` 新增 `path`（完整 exe 路径）+ `cmdline`（命令行）。
    - `process_image_path(pid)`：复用 `QueryFullProcessImageNameW` 返回**完整路径**（原 process_name 只取文件名）。
    - `process_command_line(pid)`：用 `NtQueryInformationProcess(ProcessCommandLineInformation=60)` 取命令行；
      返回结构是 UNICODE_STRING（x64：Length@0、Buffer 指针@8），解析出宽字符串。best-effort，取不到返回空。
    - 命令行含项目路径（如 `node C:\proj\hussar-front\node_modules\vite\bin\vite.js`），直接看出项目。
  - `src-tauri/Cargo.toml`：windows 依赖新增 `"Wdk_System_Threading"` 特性（NtQueryInformationProcess 在 `windows::Wdk::System::Threading`）。
  - 前端 `src/types.ts` PortProcess 加字段；`src/modules/port/PortPanel.tsx` 结果条目新增「路径 / 命令行」详情区；`port.css` 加等宽样式。
- 校验：tsc 通过；cargo check 通过（重编 windows crate ~3min，target 此前被删）。
- **可复用技术点（Windows 取进程命令行）**：windows crate 0.61 用 `Wdk_System_Threading` 特性 +
  `NtQueryInformationProcess` + `PROCESSINFOCLASS(60)`；返回 UNICODE_STRING，x64 下 Buffer 指针在偏移 8 处。
