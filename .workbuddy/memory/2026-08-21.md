## 语速贴面板接入全局快捷键（commit 07310b4，不推送）
- 主人问"语速贴面板怎么没有快捷键设置"——快捷键系统是**硬编码清单**，
  当初加语速贴功能时漏接入，三处各有独立清单需同步补：
- 改动（6 文件，默认 Alt+K，K=快捷/Quick，与现有 Alt+C/F/A/S/P/Q 不冲突）：
  1. `config.rs`：ShortcutsConfig 新增 `snippets` 字段 + 默认 "Alt+K"
     （ShortcutsConfig 已带 `#[serde(default)]`，旧配置缺字段自动补默认，无缝兼容）。
  2. `shortcut.rs`：bindings 字段、shortcut_test 冲突检查、shortcut_apply 白名单/读写/
     持久化、register_initial、register_one、panel_label_for 全部补 snippets 目标。
  3. `keyhook.rs`：新增 SNIPPETS_HOTKEY_VK/ALT_VK 静态槽、`Action::ToggleSnippets`、
     set_panel_hotkey 匹配、run_action 分发、钩子回调 Win/Alt 两分支匹配；
     Alt 诊断输出 slots 串补 `/sn:0x{:X}`。
  4. `ShortcutPage.tsx`：Target 联合类型、rows、others 冲突列表、renderRow 新增
     「呼出语速贴面板」行。
  5. `types.ts` / `configStore.ts` / `tauri.ts`：同步 snippets 字段与 applyShortcut 参数类型
     （tsc 报错暴露 tauri.ts applyShortcut 参数仍是旧 6 目标联合，一并修）。
- 验证：npx tsc --noEmit + cargo check 均通过。
- 经验：加新面板快捷键要同步 **config(默认值) → shortcut.rs(注册/持久化/路由) →
  keyhook.rs(钩子槽位+Action) → 设置页(UI行) → 前端类型/默认配置** 五层；
  纯 Alt/Win 组合走 keyhook 钩子，仅改 shortcut.rs 不生效，钩子槽位必须同步补。

## 工具栏启动默认竖排 + 定位任务栏上方右下角（commit 136a823，不推送）
- 主人要求：①启动默认竖排；②默认在屏幕右下角，但不要压在任务栏上，要放任务栏上方。
- 改动：

     `configStore.ts` 前端默认同步 vertical。
  2. `panel.rs` position_toolbar_bottom_right：`monitor.size()`（全屏区域，底部任务栏会遮挡）
     → `monitor.work_area()`（工作区=排除任务栏），工具栏贴工作区下缘=任务栏上方。

  该 data/，所以 dev 读的是 `src-tauri/target/debug/data/config.json`，不是 %APPDATA%、
  也不是项目根 data/（那是打包便携版的）。改运行时配置要找准目录。
- 踩坑：Tauri `Monitor::work_area()` 直接返回 `&PhysicalRect`（不失败），不是 Result/Option；

- 审计结论：大部分已持久化（各面板 always_on_top/剪贴板/翻译/凭证/快捷键/主题/工具栏
  enabled·tools·orientation·auto_hide/panel_positions 位置），缺 3 处：

     新增 panel_sizes: HashMap<label,(w,h)>（物理像素），toggle_panel 隐藏时 outer_size、
     呼出时 set_size（restore_size 校验 >0）。

     新增 ToolbarConfig.position: Option<(i32,i32)>；前端原生拖动无结束回调，

- 经验：加新面板要对照既有面板查配置齐不齐（always_on_top/位置/尺寸）；原生
  startDragging 无结束事件，落定判定用"轮询位置连续两次相同"最可靠。
