## 贴图右键菜单补刷亚克力（0914276）

- **现象**：贴图（pin）右键弹窗只有半透明底色，没有其他面板的亚克力模糊。
- **根因**：`pin-menu` 是前端 JS 动态创建的窗口（App.tsx 启动预建待命单例 +
  PinWindow 右键 emitTo 复用），**不在 `apply_panel_acrylic` 启动管线里**（那条只遍历
  tauri.conf.json 静态声明的 9 个面板标签）——所以从未被 apply_rounded_corners /
  apply_blur(SWCA) / make_webview_transparent 触达。
- **修复**（最小改动，仅 `PinMenu.tsx` +5 行）：菜单窗每次 `show()` 成功后
  `invoke("panel_refresh_acrylic", { label: "pin-menu" })`，与各面板 show→refresh 同序；
  命令内部读 `acrylic_enabled` 开关。useLayoutEffect 依赖 `data`（每次 emit 都是新对象），
  所以复用显示也必走补刷，顺带兜住 z-order 变化导致 SWCA 失效的老问题。
- **经验**：本项目「亚克力」统一入口 = `panel_refresh_acrylic(label)` 命令（读配置 +
  apply_panel_effects_for）。今后凡是【前端动态创建】的新弹窗，显示后都要 invoke 一次；
  窗口 CSS 半透明底（`rgba(--bg-panel-rgb, --panel-opacity)` 0.75）已就绪，无需改 CSS。
  验证仅前端改动时 tsc + vite build 即可（无 Rust 变更不用 cargo check）。

  且无选中项（工具已复位 select）。修复：loadSession 批量复位处补 `setSubmenuOpen(null)`。
  经验：**遮罩窗复用架构下，新增任何「会话态」都必须进 loadSession 的复位批次**。
- **文字输入框升级**：旧样式是裸透明框（1.5px 白描边 + 2px 圆角），观感廉价。
  新样式 = 工具栏同族实底胶囊（#f5f5f7 / rgb(32,32,33) + 1px 细描边 + 12px 圆角 +
  同款投影），**底材随文字亮度反转且与主题无关**（`isLightColor`，sRGB 加权亮度
  阈值 0.62，落在黄/橙之间）：色板同时含 #ffffff/#000000，若跟随 --tb-bg 主题翻转，
  暗主题下黑字必落深底不可读——两套材质写死、`.light-text` 类切换。
- **不可破坏的契约**：`.shot-text-editor input` 的 `bold 16px/16px sans-serif` 行盒 +
  `textBaseline="top"` + commitText 量 input `getBoundingClientRect` 三者构成文字标注
  「所见即所得」定位链，改样式只能动容器，绝不能动 input 字体/行盒。
- **二次反馈定稿（36a5f60）**：主人不要胶囊实底——文字编辑器最终形态 = **透明底 +
  方角（无圆角）+ 1px 白线 × box-shadow 外圈 1px 深线的双线边框**（任意截图内容上
  都有轮廓）+ 极轻投影；**文字一律零 text-shadow**（重影根因，编辑态=canvas 成品）。
  底材亮度反转机制（isLightColor / .light-text）整体拆除。教训：主人审美是
  「轻、透、方」的 Snipaste 式编辑器，不要往实底胶囊方向发挥；预览可读性交给
  双线边框而不是给文字加阴影。

## 画笔粗细图标：四角框随圆贴合生长（e9d5c1d，已推送 GitHub）

- **需求**：粗细圆点变大会穿过四角取景框（固定 22px，max 时穿出约 4px）；
  主人要框「贴合圆变大、融为一体」。
- **几何根据**：SVG viewBox 24 中臂尖距中心 9.85 单位 = 半幅的 0.821——圆与臂尖
  相碰的临界在 sw≈12。公式 `frame = (D+1.5)/0.821`（D=圆径）：从临界起框同心外扩，
  臂尖与圆边保持 **~0.8px 恒定细缝**（环抱感），基态 22px 不变。
- **同步动画**：框 svg 与圆 span 用同参数 `width/height 80ms ease` 过渡，
  滚轮连续调节时二者互追、严格同步滑动。
- **坑**：框 max 33.5px > 30px 按钮，居中不能用 `inset:0+margin:auto`
  （溢出时 auto margin 归零、退化为非居中偏移）→ 改 `left/top 50% + translate(-50%,-50%)`。
- **约定更新**：主人指令改为「每次完成任务 commit + push 到 GitHub」，
  MEMORY.md 已同步修正；本次起 push 到 origin main（b053bfb..e9d5c1d 含此前 7 个提交）。
