## 截图工具栏：线组二级图标可区分 + 箭头收窄（commit 3da0726）

需求（用户原话）：
1. 线段二级图标没有区分，看不出哪个代表哪个 —— 更准确说是「二次菜单没有箭头，没有线段粗细示意」
2. 默认线段样式的箭头太宽

根因：
- `IcoTapered` 与 `IcoArrow` **共用同一条** `ARROW_ICON_PATH`（从企微 PNG trace 出来的细翼 path），
  渲染出来就是一条斜线；`IcoLine` 也是斜线 → 三个二级图标视觉上完全一致。
- 三个图标 strokeWidth 恒定 = 2，与当前画笔粗细 sw 无关 → 没有粗细示意。
- 默认线段样式 = 锥形箭头（线组 items[0]，默认 sw=3）。`drawShape` 里锥形头
  **半宽** wHead = 1.0× 线宽，实际张开 2×wHead = 2× 线宽 → 偏宽。

改法（src/modules/screenshot/ScreenshotOverlay.tsx）：
- 新增 `icoW(sw) = clamp(1.5 + sw*0.2, 1.7, 5.4)`，把 1~24 的画笔粗细映射到图标可辨的 viewBox 单位。
- 三个图标组件签名改为 `({ w = 2 }: { w?: number })`：
  - 锥形箭头 = 实心锥形多边形（尾半宽 0.3w → 杆根 0.62w → 头翼 1.05w），fill 渲染 + rotate(-45 12 12)
  - 箭头 = 等宽杆身 + 端部 V 形双翼（描边镂空），翼半展 min(6.4, 2.4 + 0.78w)
  - 直线 = 纯斜线，笔画粗细 = w
- 新增 `type ToolIcon = (p: { w?: number }) => JSX.Element;`，
  `TOOL_BUTTONS` / `applyToolButton` / `btnTip` 三处签名同步改（**tsconfig 开了 noUnusedLocals，
  函数签名不匹配会报 TS2345「Target signature provides too few arguments」**）。
- 渲染处 `<MainIcon w={icoW(sw)} />` / `<Ic w={icoW(sw)} />`，滚轮调粗细时图标实时变粗。
- `drawShape` 锥形头：wHead 1.0× → **0.72×** 线宽，wTail 0.18× → 0.22×。
- 顺带：经典箭头翼长由固定 16px 改为 `min(max(7, 3×线宽)×scale, 16×scale, len*0.3)`。
- 移除不再使用的 `ARROW_ICON_PATH` 导入（noUnusedLocals 会报错）。

验证：tsc --noEmit 通过；vite build → dist-v8，robocopy /MIR 到 dist，重启应用（PID 13492）。

## 截图工具栏 · 第二轮（commit 07ee3ce）：锥形箭头尾部/头部造型 + 图标细长

需求：1) 默认线类型尾部过于细，粗一点 2) 箭头头部是纯三角，应该在三角形底部
再凹进去一个三角（指向感更强）3) 锥形箭头二级图标短粗，要细长但不能细到认不出
线型；箭头（第二种）图标也偏短。

关键根因（值得记住）：旧版 `drawShape` 的 tapered 分支尾端是 `moveTo(X1,Y1)`
**一个点** —— 尾部宽度收到 0，所以看着像针。`wTail` 其实是用在【头部那端】的
（肩宽），不是尾端，读代码时极易误判。

新版锥形箭头几何（局部坐标：x 沿箭头 尾→头，y 法向）：
- hl = min(max(8, 2.8×线宽)×scale, 0.45×len)   头长
- nd = 0.42×hl                                  凹口深度（底边朝尖端挖进去）
- wTail = max(0.9, 0.38×线宽)                   尾端半宽（平尾，非尖点）
- wShaft = max(1.2, 0.55×线宽)                  杆身到凹口顶点时的半宽
- wBarb = max(1.8, 0.72×线宽)                   倒刺（最宽处）半宽
- 倒刺底边 b = (X2 - ux·hl)，凹口顶点 k = (X2 - ux·(hl-nd))，尖端点 = X2
- 7 点轮廓顺序：尾上缘 → k(-wShaft) → b(-wBarb) → 尖端 → b(+wBarb)
  → k(+wShaft) → 尾下缘 → close
  （**k 必须在 b 之前方**，即凹口顶点比倒刺更靠近尖端，否则凹口看不见）

图标（viewBox 24，先画水平再 rotate(-45 12 12)）：
- 锥形：尾 2.3 → 尖 21.8（全长 19.5）；倒刺底边 12.8、凹口顶点 15.6；
  tw=max(0.5,0.24w) / kw=max(0.8,min(2.6,0.44w)) / hw=max(2.0,min(4.0,0.95w))
  → 头长:头宽 ≈ 2.2（细长）；hw 下限 2.0 保证细画笔下仍能认出线型
- 箭头：杆身 2.8→20.8（原 3.2→19.4），V 顶点同在 20.8（与杆身圆头端点外缘齐平，
  尖端不出毛刺），V 底 12.0，翼半展 hl = min(4.3, 1.8+0.44w)（原 2.4+0.78w，收窄）
- 直线：(3.8,20.2)→(20.2,3.8)，与另两个等长

## 截图工具栏 · 锥形箭头第 4 轮：尾部改「内凹燕尾」(commit ab0d4e9)

用户手绘图反馈三件事：① 尾部为什么是平的，常规箭头尾部是向内凹的；
② 上一轮尾部加粗加过头（0.38×线宽 → 2.28px @sw3，像木桩），只要"稍微粗一点点"；
③ 整体看不出是箭头，像木桩。

第 3 轮(fcd1ef1)先做了 ② ③ 的参数再平衡：wTail 0.38→0.16、wShaft 0.55→0.50、
wBarb 0.72→0.95、凹口深 nd 0.42→0.55×hl（窄杆身 → 深 V 口 → 宽倒刺，层次才出来）。
第 4 轮(本轮)做 ①：
  - 画布 drawShape 锥形分支：尾缘从「直线 closePath」改为二次贝塞尔
    ctx.quadraticCurveTo(X1 + ux*td*2, Y1 + uy*td*2, X1 - nx*wTail, Y1 - ny*wTail)
  - 深度 td = min(max(1.2*scale, wTail*2.2), len*0.15)  ≈ 1.1×尾全宽

## 截图工具栏 · 两种箭头第 5 轮 (commit 5c1f7c3 附近)

用户反馈：① 默认线段（锥形）箭头看不清，像木桩/削过的铅笔，头应向外侧+向后延伸；
② 第二种线段（经典箭头）头上的"肩头尖儿"没了。

根因与修法：
- 锥形：hl 上限 2.8×线宽/下限 8px 太小、wBarb 0.95×线宽/上限 8px 太窄 → 改
  hl=max(11, 4.5×线宽)（上限 len×0.5）、wBarb=max(2.6, min(20, 1.6×线宽))。
  注意 wBarb 写法：min(20, w*1.6)*scale —— 20 是 CSS px 上限。
- 经典箭头「尖儿没了」根因：旧实现从尖端 ctx.stroke() 两条边，粗线下两翼与
  杆身糊成一团，且翼端被圆头线帽磨成圆头 → 改为 chevron 填充多边形：
  T(尖端) → E+(上翼尖) → V_in(凹口, 距尖端 hl*0.35) → E-(下翼尖)，四点皆尖；
  翼展 sw=hl*0.55；杆身收在 xEnd = hl*(lineWidth/2)/sw 处（chevron 外缘=杆宽，
  无缝也不戳出尖端），lineCap=butt。这个 xEnd 公式让粗线时翼自然比杆宽。
- 图标 IcoArrow 同步改 chevron 填充；IcoTapered 头部加长（倒刺底边 12.8→11.2）。

经验：Canvas 里「描边线」当箭头翼在大线宽下必然糊掉 —— 箭头头部一律用
填充多边形，翼尖要尖就别依赖 lineCap（butt 也只是平口，不是尖点）。
