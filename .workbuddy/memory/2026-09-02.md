## 全局命令面板重写 + 本机应用扫描补全

### 1. 命令面板 UI 重写（主人反馈：样式单调 / 信息少要滚动 / 颜色没区分度）
- `CommandPalette.tsx` 重写为**左分区导航 + 右双行结果**：
  - 左栏按来源（kind）分区，带全量命中计数（`counts` 来自 `QueryResult`，不受展示限流缩水）；
  - 点击或 **Tab / Shift+Tab** 循环切换分区；Esc 语义改为「先清分区再关窗」；
  - 行改双行（标题 + 副标题），行尾 tag / 热键 / Ctrl+Enter 提示；
  - 每个来源一个主题色（`KIND_COLOR`，走 `--tool-*` token，`color-mix` 派生底色描边），
    图标座 / 分区头 / 左栏点 / 色条统一用该色；
  - 分区头吸顶（`position:sticky`，实底 `--bg-elevated`，勿用 backdrop-filter）；
  - PageUp/PageDown/Home/End 翻页；窗口 680×480 → **780×600**（tauri.conf.json）。
- `commands.ts`：`queryItems/emptyStateItems` 返回 `QueryResult{items,counts}`；
  分区限流 PER_GROUP=10、TOTAL=80，聚焦分区放宽到 FOCUS_GROUP=40；
  换词才 120ms 防抖（`lastQueryRef` 区分），仅换分区 0ms 重算；
  **空态常驻「本机应用」前 30 条**（EMPTY_APPS）——此前空态完全没有应用，
  是"扫不到应用"观感的一部分。
- `types.ts`：新增 `KIND_ORDER` / `KIND_COLOR`。

### 2. 本机应用扫描补全（主人反馈：微信、企业微信扫不到）
- 旧版只有 开始菜单.lnk + App Paths 两个来源；新增：
  - **卸载表注册表**（HKLM/HKCU × WOW64 32/64，DisplayName + DisplayIcon/InstallLocation），
    微信/企业微信这类用户级安装的唯一可靠登记处；过滤 SystemComponent/补丁/KB；
  - **常见安装目录扫描**（Program Files ×3 + LOCALAPPDATA\Programs + LOCALAPPDATA，
    下钻 2 层，只认"主 exe 与所在目录同名（或父目录为版本号+祖父同名）"，
    4000 目录 / 2500ms 预算兜底）。
- 拆分：`apps.rs`（命令+内存/磁盘缓存）+ `apps_scan.rs`（纯扫描，无 crate 依赖）。
- junk 修正：**短关键字（≤6 字符）只在"显示名/文件名"上匹配**，不再对整条路径 contains
  （否则 `cmd/calc/store` 这类片段在长路径里误伤）；补 `upgrader/clicktorun/sdxhelper/
  skypeserver/msoxmled/msoadfsb/msoasb/vcpkg`（Office/套件辅助进程实测混入）。
- 启动菜单名优化：`微信/微信` → `微信`（目录名=快捷方式名时去重）。
- **真机验证**（临时 bin `src/bin/appscan.rs`，验证后已删）：
  开始菜单=111 卸载表=34 AppPaths=44 目录=19 → 去重 106 条；
  微信→`D:\...\Weixin\Weixin.exe`、企业微信→`WXWork.exe`、QQ 全部命中；
  耗时 1.8s（首次 14s 是冷缓存+双扫，含图标提取）。
- **启动预热**：lib.rs setup 里 `std::thread::Builder("app-scan")` 后台跑
  `apps::warm_from_disk`（读 `data/app_cache.json` → 过期(24h)才重扫 → 落盘）；
  `list_installed_apps` 命中缓存零等待返回，过期先交货后台重扫。
- 缓存文件：`storage.rs` 新增 `app_cache_file = data/app_cache.json`（含图标约 1MB）。
