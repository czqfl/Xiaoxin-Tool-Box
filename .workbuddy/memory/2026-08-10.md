## Snipaste 图片进不了剪贴板历史（commit 后补）

### 根因（两点叠加）
1. **arboard 只读 CF_DIB**：arboard 在 Windows 的 `get_image()` 只读 CF_DIB 位图；
   Snipaste 复制图片主要写入 EMF/PNG 格式，DIB 缺失/解析失败时图片被静默丢弃（`if let Ok` 吞错）。
2. **优先级**：原 `read_clipboard` 是「文件 > 图片 > 文本」，若复制内容附带文件列表(CF_HDROP)，
   图片会被误判为文件复制。

### 修复
- `read_clipboard` 优先级改为「图片 > 文件 > 文本」。
- Windows 新增 `read_png_from_clipboard()`：`OpenClipboard` + `EnumClipboardFormats` 枚举，
  匹配名为 "PNG" 的自定义格式，`GetClipboardData` + `GlobalLock/GlobalSize` 读字节，
  用 `image::load_from_memory` 解码为 RGBA 兜底。兼容 Snipaste 和 Win10/11 系统截图。
- Cargo.toml windows features 增加 `Win32_System_DataExchange`、`Win32_System_Memory`。
- **windows 0.61 API 坑**：`GetClipboardData` 返回 `Result<HANDLE>`、`GlobalLock` 返回裸指针、
  `GlobalSize` 返回 `usize`、`GlobalUnlock` 收 `HGLOBAL` 返回 `Result<()>`；HANDLE→HGLOBAL 需 `HGLOBAL(h.0)` 手动包装。

## 剪贴板记录提速（10:28 轮）— 事件驱动 + 异步保存

- 用户反馈"复制挺久才出现"：500ms 轮询 + 大图 PNG 编码阻塞监听线程（秒级，事件不发）。
- **事件驱动**：`clipboard_listener` 模块（cfg windows）创建隐藏窗口 + `AddClipboardFormatListener` 监听
  `WM_CLIPBOARDUPDATE`，经 mpsc channel 唤醒 watcher 立即读取；500ms `recv_timeout` 保留作轮询兜底。
- **图片异步保存**：`build_entry` Image 分支 spawn 线程保存（先缩略图后原图），条目立即入库广播，
  前端 `ImageThumb` 失败自动重试 6 次 × 400ms 兼容抢跑。
- **PNG Fast 压缩**：`save_png_fast` 用 `PngEncoder::new_with_quality(CompressionType::Fast, FilterType::Adaptive)`。
- windows 0.61 注意：`AddClipboardFormatListener` 在 `Win32_System_DataExchange`（不在 WindowsAndMessaging）；
  `GetModuleHandleW` 返回 `HMODULE` 需 `.into()` 转 `HINSTANCE`；`WNDCLASSW.style` 是 `WNDCLASS_STYLES`（Default 即可）；
  `CreateWindowExW` 的 hInstance 参数是 `Option<HINSTANCE>`。
- 待办（上轮遗留）：SUPPRESS_WATCH 残留吞记录 bug 未修。

## 面板模糊必须点击才出现（14:40 轮）

### 根因
- 面板用 `DWMWA_SYSTEMBACKDROP_TYPE = DWMSBT_TRANSIENTWINDOW`（mica），该材质只在"活动窗口"绘制。
- 面板靠 `show()+set_focus()` 程序化呼出，Win32 严格前景规则常拒绝真正置前，DWM 视作 inactive → 不画材质；
  用户点一下面板才真正成为前台窗口 → 模糊出现。即"只有点击才出模糊"。

### 修复
- `acrylic.rs::apply_acrylic` 改为 `DWMSBT_MAINWINDOW`（acrylic）：窗口可见即绘制，与激活无关 → 永久模糊、无需点击。
- `panel.css`：移除 `:not([data-panel-focused])` 失焦加深底色规则（那是给 mica 退化实色打的补丁，会挡住 persistent acrylic）；
  shell 背景改用 `--panel-opacity`（去掉 `--shell-opacity` 覆盖分支）。
- `usePanel.ts`：删除已无用的 `markPanelFocused`（focus/blur 监听保留，仍负责失焦自动隐藏）。
- lib.rs / acrylic.rs 注释同步更新；Win10 上该属性不存在，调用失败回退普通窗口（无材质但不黑），无回归。
- 编译验证：`cargo check` + `npm run build` 均通过。
