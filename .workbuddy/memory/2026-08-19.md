## 加宽便签恢复按钮 + 快捷键关闭播特效（commit 76b80d7）
- ①【加宽后收起按钮不恢复】根因：adaptTitlebar 用 `titlebar.clientWidth < 380`
  硬门槛——宽到 380 以下强制收起 3 按钮；且自适应只在 RAF + onResized 触发，
  原生缩放拖拽(startResizeDragging) 不触发 onResized → 加宽后不重算。
  修复：改纯内容溢出判定（去掉 380 门槛）；新增 ResizeObserver 监听
  document.documentElement（Webview 与窗口同尺寸，任何缩放都触发），兜底重算。
  注意：toggle .crowded 改的是标题栏内部布局、不改变窗口尺寸，ResizeObserver
  不会自循环。
- ②【快捷键关闭无特效】根因：show_app(show_all_open) 与工具栏便签入口
  (toggle_sticky_notes) 收起分支直接 w.hide()，从未 emit 本就存在的
  play-close-anim 事件（该事件仅前端 × 按钮/旧"全部关闭"用）。修复：收起时
  对每个 VISIBLE_NOTES 内便签窗口 emit play-close-anim → 前端聚焦窗口播粒子
  消散、其余立即收尾，动画结束 finishClose→close_window 自行清理 VISIBLE_NOTES
  + 广播状态；不再此处 hide()/clear()。透明主题无粒子动画属预期。
- 教训：原生 resize 拖拽不保证发 onResized，尺寸自适应要 ResizeObserver 兜底；
  全局快捷键的收起语义应与 × 按钮一致（走关闭动画事件）。

## 标题栏重叠 + 快捷键关不掉——整体重写（commit 4adb3db）
- 用户反馈前两轮流修补仍无效，要求重做逻辑。从根重构，不再局部修补。
- 【标题栏重叠根因（修正前两轮误判）】：`.titlebar` 上的 `overflow:hidden` 让
  `scrollWidth > clientWidth` 检测失效 → `.titlebar.crowded`（窄窗隐藏次级按钮）
  几乎从不触发；且 `.titlebar-grip` 用 `flex:1 1 0` 弹性占位，在中等宽度下与右侧
  按钮边界打架。前两轮修的是"圆点溢出"(overflow:hidden on grip) 属错方向。
- 重写方案：①`.titlebar` 去掉 `overflow:hidden`，让 `.crowded` 检测恢复；
  ②`.titlebar-grip` 改为固定 `flex:0 0 54px` 的 flex 兄弟元素（flex 兄弟天然不重叠，
  配 `justify-content:space-between` 仍居中）；③`.titlebar-left` 去掉 `max-width` 限制
  + 加 `overflow:hidden` 裁标题；④`.title-input` 加 `min-width:0` + 截断。
  无论多窄，三层（标题/抓取区/按钮）稳定并排，绝不再重叠。
- 【快捷键关不掉根因】：关闭完全委托前端 `play-close-anim` 动画回调去真正销毁窗口，
  动画模块回调一旦未触发即"关不掉"。重写：Rust 端做权威兜底——收起时广播动画特效后，
  另起主线程定时器（700ms）强制 `close_note_window_by_label` 销毁每个便签窗口；
  前端若正常播完会先关，定时器届时变 no-op（幂等安全）。
- 新增 `close_note_window_by_label`（统一销毁+几何回写+状态清理，单一真相来源）与
  `schedule_force_close`（主线程兜底定时器）；`close_window` 便签分支委托前者，逻辑收敛。
- 验证：tsc + vite build + cargo check 全通过；已 commit 未 push。
- 待实测（tauri dev 重启）：①窄到极限标题栏不重叠、次级按钮正确隐藏；②快捷键一次
  按下即收起（含历史面板打开的便签）且带关闭特效。
