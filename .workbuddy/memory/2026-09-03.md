
## 马赛克：偏亮修复 + 二级选项（5758472，2026-09-03）

### 反馈1 马赛克块偏亮（对比企业微信）
- 根因：drawShape 马赛克分支整图层一步大比例降采样（W->pw 可达 100x），
  Skia/Chromium 双线性大比例下退化成稀疏跳采样，白底黑字区域黑像素被漏采，
  格子颜色被拉向亮底色。
- 修复：逐级减半降采样（每步 <=2x）。数学根据：目标像素 i 中心 i+0.5 反投影
  回源图 = 2i+1.0，恰好落在相邻两纹素中心（2i+0.5/2i+1.5）正中，双线性四权重
  各 0.25 = 精确 2x2 区域平均；逐级递归即全图真实均值，偏暗更实。
- 中转画布 mosaicScratch 加 dsA/dsB 两块（交替用，避免自绘自）。

### 反馈2 马赛克二级选项（手绘 / 选区，配置持久化）
- Anno 加 mshape?: draw|rect；cfg.annotate.mosaic_mode 持久化（缺省 draw）。
- types.ts / configStore.ts / src-tauri/config.rs 三处同步加字段（Rust 端
  #[serde(default)] 容器级 + Default 里 mosaic_mode: draw.into()）。
- 二级面板：tool===mosaic 时 renderConfigPanel 渲染两个模式按钮，
  图标仿企业微信 = Lucide Pointer（手绘）+ BoxSelect（选区），
  写法与 IcoBrush=<Pencil {...IC}/> 同构。
- 一级图标恒定不变（主人明确要求，MainIcon 不随子模式换）。
- onDown：mosaicIsRect 时 points=undefined、只记对角两点；onM 走 x2/y2 更新
  （与矩形同构）。松手后 shapeEditable 含 isRectMosaic -> 可移动/缩放。
- drawShape：isRect 时蒙版 fillRect 整个包围盒（pad=0），destination-in 后
  选区内整块马赛克；手绘仍走圆头粗线蒙版。
- 选区模式单击未拖动（<2px）松手时按 sid 丢弃空记录，不白占撤销。
- mosaicScratch mask/comp 改只增不减 + 全部 drawImage 带源矩形，拖选区
  逐帧变大不再每帧重分配位图（全屏选区 8MB/帧x2 的浪费）。

### 教训：并行 Edit 同一文件互相覆盖
- 同一条消息里对同一文件发 3 个并行 Edit，只有最后一个生效（前两个被
  读-改-写回的旧快照覆盖），tsc 报 isRectMosaic 未定义才暴露。
- 铁律：同一文件的多个 Edit 必须串行发，绝不并行。

## 马赛克反馈第二轮（fe15658，2026-09-03）

### 反馈3 手绘图标（Pointer）矮胖
- 保留 Lucide Pointer 原始路径（从 node_modules/lucide-react/dist/esm/icons/
  pointer.mjs 核实），不再用 <Pointer {...IC}/> 组件，改自绘 SVG：
  g transform=translate(12 12) scale(0.9 1.1) translate(-12 -12) 以中心
  横向收 0.9、纵向拉 1.1 -> 细高匀称；每个 path 加
  vector-effect=non-scaling-stroke 保证描边不随 transform 变形。
- Pointer 组件从 import 中移除（避免 unused）。

### 反馈4 选区马赛克拖动时没有边框、松手才出现
- 根因：二次编辑装饰（虚线框+手柄）由 editIdx>=0 驱动，而 editIdx 在
  onU（松手）才 setEditIdx -> 拖动全程无框，马赛克与原图颜色接近时
  选区边界不可辨。
- 修复：新 state drawRectMosaic，onDown(mosaicIsRect) 置 true、onU 先清；
  装饰 effect 的 es 兜底取 annos[annos.length-1]（onM 里 last 元素被整体
  拷贝替换，length-1 才是最新矩形），依赖数组加 drawRectMosaic。
- 拖动中只画虚线框不画手柄（落点没定型，手柄是视觉噪音）；松手后
  editIdx 接管才带手柄。
