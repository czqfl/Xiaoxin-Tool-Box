
## 马赛克：偏亮修复 + 二级选项（5758472，2026-09-03）

### 反馈1 马赛克块偏亮（对比企业微信）
- 根因：drawShape 马赛克分支整图层一步大比例降采样（W->pw 可达 100x），
  Skia/Chromium 双线性大比例下退化成稀疏跳采样，白底黑字区域黑像素被漏采，
  格子颜色被拉向亮底色。
- 修复：逐级减半降采样（每步 <=2x）。数学根据：目标像素 i 中心 i+0.5 反投影
  回源图 = 2i+1.0，恰好落在相邻两纹素中心（2i+0.5/2i+1.5）正中，双线性四权重
  各 0.25 = 精确 2x2 区域平均；逐级递归即全图真实均值，偏暗更实。
- 中转画布 mosaicScratch 加 dsA/dsB 两块（交替用，避免自绘自）。

### 反馈2 马赛克二级选项（手绘 / 选区，配置持久化）
- Anno 加 mshape?: draw|rect；cfg.annotate.mosaic_mode 持久化（缺省 draw）。
- types.ts / configStore.ts / src-tauri/config.rs 三处同步加字段（Rust 端
  #[serde(default)] 容器级 + Default 里 mosaic_mode: draw.into()）。
- 二级面板：tool===mosaic 时 renderConfigPanel 渲染两个模式按钮，
  图标仿企业微信 = Lucide Pointer（手绘）+ BoxSelect（选区），
  写法与 IcoBrush=<Pencil {...IC}/> 同构。
- 一级图标恒定不变（主人明确要求，MainIcon 不随子模式换）。
- onDown：mosaicIsRect 时 points=undefined、只记对角两点；onM 走 x2/y2 更新
  （与矩形同构）。松手后 shapeEditable 含 isRectMosaic -> 可移动/缩放。
- drawShape：isRect 时蒙版 fillRect 整个包围盒（pad=0），destination-in 后
  选区内整块马赛克；手绘仍走圆头粗线蒙版。
- 选区模式单击未拖动（<2px）松手时按 sid 丢弃空记录，不白占撤销。
- mosaicScratch mask/comp 改只增不减 + 全部 drawImage 带源矩形，拖选区
  逐帧变大不再每帧重分配位图（全屏选区 8MB/帧x2 的浪费）。

### 教训：并行 Edit 同一文件互相覆盖
- 同一条消息里对同一文件发 3 个并行 Edit，只有最后一个生效（前两个被
  读-改-写回的旧快照覆盖），tsc 报 isRectMosaic 未定义才暴露。
- 铁律：同一文件的多个 Edit 必须串行发，绝不并行。

  onU（松手）才 setEditIdx -> 拖动全程无框，马赛克与原图颜色接近时
  选区边界不可辨。

  装饰 effect 的 es 兜底取 annos[annos.length-1]（onM 里 last 元素被整体

- 拖动中只画虚线框不画手柄（落点没定型，手柄是视觉噪音）；松手后
  editIdx 接管才带手柄。

## 马赛克审计：快照内存泄漏修复（d364ec5，2026-09-03）

### 缺陷：时序快照无上限累积
- captureMosaicUnderlay 每条马赛克落笔拍一张整屏物理分辨率画布
  （2560x1600x4 约 16MB）。撤销后快照保留（重做需要，合理），但重做栈
  被新动作清空后，被撤销的马赛克永远回不来 -> 快照永久孤儿，
  画/撤/画循环无上限累积，直到会话结束才 clearMosaicSnapshots。
- 修复：新增 pruneMosaicSnapshots(keep) + collectAnnoSids(annos)，
  在每个清重做栈的位置调用：onDown 落笔（keep 含本条新 sid）、
  commitText、startShapeMove、startShapeResize（keep=当前 annos）。
  正常撤销（不清重做栈）不 prune，快照保住供重做。
- 已知残留：undo 栈 slice(-99) 挤压出的历史马赛克快照要等下次
  prune 才回收，会话内有限、可接受。

### 保险：drawRectMosaic 跨会话残留
- 若会话在选区马赛克拖拽中被强制收场（Esc），onU 不触发、标记残留 true。
  遮罩窗复用（组件不卸载），理论可污染新会话兜底装饰。已在会话重置
  （reset 分支）与 showHistFrame 两处加 setDrawRectMosaic(false)。
  实际被 shapeEditable(es) 兜底保护（手绘马赛克不可编辑），危害低，
  但按零隐患原则显式清。

### git 链式误报再现
- add+commit+push 链报 nothing to commit / ahead by 1，实为 commit 成功
  push 未执行。按既定流程 git log + status 复核后单独 push 解决。

## 长截图·滚动顿挫 + 接口错位双修复（484e11e，diag 日志实锤）
- 接口错位根因①：旧对齐评分逐行独立 ±2px 邻域取最小差 → 重复纹理下整体错位假匹配合格 + score(p±1) 失真，整像素滚动也输出 frac 恒 0.50 伪影；根因②：Bresenham 亚像素补偿被伪影骗着每两步 ±1 行乱切（日志 err 交替 -0.50/0.00），每次切割接口错一行。
- 修复：score_at 改「整体偏移」评分（±2px 五种整体错位各算条带总差取最优，行间关系保持）；移除 Bresenham，分数滚动交给衔接行 trim 丢混合行（代价：总高每步可能少 1px，无感）。
- 顿挫根因：停稳判定=相邻两抓帧逐字节相同，120ms 粒度动画结束后再等 1~2 周期（实测步间隔 0.55~1.4s 抖）。CAPTURE_INTERVAL_MS 120→60。
- 教训 reinforcement：Read 工具显示与真实文件不一致（675 行实际是 `sub_err += trim as f64 + frac;`，Read 显示 `sub_err += frac;`）——改 Rust/关键文件前必须用原生 python 打印真实内容核对；Edit 工具 old_string 基于显示层会 match 失败，改用 python 行号切片 + assert 锚点行。

## 二级选项栏双框修复（ae69759）

## 截图反馈⑤（793dee8）：画笔缩放 + 字号滚轮大A + 文字上移修复
- 画笔可缩放：shapeHandles 纳入 brush 四角手柄；startShapeResize brush 分支按原始包围盒→锚点/光标新包围盒等比映射整条 points（每次从 orig 重算不累加，线宽不变）。
- 字号滚轮：IcoFontSize 大 A（22px 方寸内 8~72 线性映射 9~20px，A 的大小随字号实时变化）；text 二级面板按钮 onWheel 无级调节（Shift 加速 4 步），fontSize 400ms 防抖写盘广播。
- 文字上移根因：DOM input 行盒与 canvas 基线锚点不同——input 改 line-height:normal，commitText 存「行盒顶部 + fontAscent(字号)」= 基线，canvas 删 textBaseline="top" 用默认 alphabetic 画同一基线，严格同位；fontAscent 用 measureText fontBoundingBoxAscent 实测缓存（TEXT_FS_DEFAULT=18/MIN=8/MAX=72，types/configStore/config.rs 三端 font_size 已齐）。

## 长截图·拼接核心重写（d37ef99）：帧间物理窗口 + 三重验证
- 主人反馈「滚了很长图很短」：diag 实锤手动滚动时 last_shift hint 窗过窄套住错误匹配，每步只拼 3~21px（实际 ~100px），位移被系统性低估、内容静默丢失。
- 开源调研：xutianyi1999/scrollshot（Rust/Windows/Win32 滚轮注入 + 拼接，MIT，2026-08 活跃，cargo install 可用）——关键设计「Previous scroll distances never narrow or bias the search」；管线 = 灰度+正文栏检测 / Sobel 特征 / 多模板高度 NCC 并行 / 粗到精 / 验证（相关阈值+局部/全局置信度边际+SSE）/ 安全重试（10 次恢复）/ 停滞检测到底。另参考：ShareX（C# 滚动捕获）、ScrollSnap（macOS Swift）。Tauri 生态无现成库，借鉴算法重写自有核心。
- 重写内容：①find_align 改物理窗口 [c.h-fh, c.h-MIN_OVERLAP]（几何必然，删 hint/全画布回退/last_shift）②全局置信度边际 MARGIN_AMBIGUOUS=4（次优差 <4 拒收，防重复纹理多峰）③位移守恒校验（自动滚动时 |shift-expected|<=max(0.45e,48px)，失配清 pending 防卡死）④连续拒收>=3 强制接受（防永久卡死）⑤THRESH_ALIGN 22->30（整体偏移评分更严）。
- 工具教训：超长内联 heredoc python 脚本传输会丢字符（NameError: 'l'），必须 Write .py 文件再执行；cargo 报 `<` 泛型歧义时 `diff as u64 < X` 要写 `(diff as u64) < X`（后跟块时）。
- 验证：cargo check 零警告 ✓ / CRLF 完好 ✓ / push ✓。待主人真机验证。
