## 录屏（recorder）功能修复 ×4 + 弹窗重构（未 commit）

### 1. 录像文件损坏（根因：AVI 头部字段错位）
- `src-tauri/src/avi.rs`：`avih_suggest_buf_pos` 记的是 `avih_body + 36`（正是 **dwHeight** 的偏移），
  `finish()` 回填 `dwSuggestedBufferSize` 时把帧最大 JPEG 大小（几万~几十万）写进了 dwHeight → 播放器判文件损坏。
- 修复：`avih_body + 28`（dwSuggestedBufferSize 正确偏移）。dwHeight 保持真实高度。

### 2. 配置面板位置（按用户要求重做）
- `RecorderSelect.tsx`：面板优先放【非录制区域（遮罩）右下方】= 屏幕右下角；
  若该位置压到录制区域（遮罩处放不下）→ 放到【录制区域右下方】= 选区内部右下角。
- 布局 effect 用真实尺寸精确夹回；去掉了旧的 translateX(-100%) 锚定 hack。

### 3. 录制中遮罩/交互（两个问题一个根因）
- 根因：录制中选区窗（rec-select）仍是置顶 OS 窗口，DOM `pointer-events:none` 挡不住 OS 层
  hit-test → 整屏鼠标输入被吞（"无法操作屏幕"）；且选区窗未排除出屏幕采集（遮罩/边框会录进视频）。
- 修复（`src-tauri/src/recorder.rs`）：
  - `recorder_start`：`window.set_ignore_cursor_events(true)`（鼠标穿透，可正常操作屏幕）+
    `exclude_from_capture(hwnd)`（遮罩/脉冲边框绝不进视频）。
  - `begin_select` 复用路径：重置 `set_ignore_cursor_events(false)`（否则上次录制后选区窗无法拖拽）。
- 权限 `core:window:allow-set-ignore-cursor-events` 已在 default.json（Rust 侧调用本就不受 capabilities 限制）。

### 4. 完成弹窗重构（RecorderBar.tsx + recorder.css，与 #2/#3 同轮）

- 前端用 `window.screen.availLeft/Top/Width/Height`（工作区，已排除任务栏）定位到当前显示器右下角，
  多显示器也正确（Rust `recorder_bar_popup` 用 monitor size 含任务栏 → 弹窗会落在任务栏后被遮，已弃用）。
- 按钮：打开（`quickfiles_open(path, null)` 默认程序播放，失败回退打开文件夹）/ 文件夹 / 关闭；6 秒自动关。
