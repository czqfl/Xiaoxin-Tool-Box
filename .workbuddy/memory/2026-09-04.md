### 贴图接口三条硬约定（复用 pin_create 必读）
1. Rust `create_from_b64` 直接 `base64::decode(b64)`，**不剥离 `data:image/png;base64,` 前缀**
   → 前端必须传纯 base64，否则解码直接失败。
2. `pin_create` 的 x/y 是**物理像素**屏幕坐标（与截图贴图路径同约定）；PNG 像素尺寸即贴图
   窗口尺寸，故渲染按 `monitor.scaleFactor` 放大，125%/150% 缩放下字号恒定不发虚。
3. 落位取 `currentMonitor()` 中心：按钮位置就是面板位置，贴那儿会被面板自己盖住。

### 渲染细节
- 卡片：深灰蓝 #20232e + 1px 浅描边 + 圆角 12；字号 15 / 行高 24 / 内边距 18×15 / 最宽 460。
- 断行：CJK 与中文标点逐字可断，西文按词（不在词中断），超宽长串（URL）按字符硬切。
- 兜底：上限 30 行 / 4000 字符，超出截断加省略号（避免贴图高过屏幕）。

### 工具坑：Edit 写 `\uXXXX` 会被 JSON 转义成双反斜杠
- 想写正则 `/[\u2e80-\u9fff]/`，Edit 参数里 `\\u2e80` 落到文件变成 `\\u2e80`（双反斜杠，语义错）。
- 解法：改用 python 脚本 raw string 精确替换（`r"/[\u2e80-...]/"`），并顺手把新建文件行尾
  统一成 CRLF 与同目录一致（Write 新建的文件默认是 LF）。

## 剪贴板补全：图片条目贴图（0cd2e57，已推送）
- 缺口：上轮文字贴图把 image 类条目排除了（贴图应贴原图而非渲染文字）。

- 落位：work_area 中心（物理像素，与 pin x/y 同约定）；mime 按扩展名判断。
- 前端：移除 kind!=='image' 限制，image 走 clipboardPinImage(id)、文字走
  pinTextToScreen；title 按类型区分（钉图/钉文字）。
