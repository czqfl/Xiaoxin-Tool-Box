  2. 历史窗口从不监听便签状态事件（sticky://open-changed）→ 列表不刷新；
  3. 历史/便签窗口关闭不广播可见性 → 工具栏高亮不取消。
- 修复：
  1. close_window 重写：便签 hide → mark_note_closed_inner（移除打开中）+
     emit open-changed（历史刷新）+ 广播可见性 false（工具栏高亮取消）；
     历史/设置 close → 广播 false。
  2. ensure_note_window（显示现有）/create_note_window（新建）→ 广播可见性
     true + emit open-changed。
  3. history.ts 监听 sticky://open-changed → render()（列表实时刷新）。
