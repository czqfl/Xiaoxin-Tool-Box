## 贴图 OCR 弹窗修复（commit 96798e3）
主人反馈三问题：①弹窗在外部时按完 Alt 闪一下就消失；②位置会乱跳/切换；③应放外面且贴图缩放切换位置不应再调翻译接口。
根因与修复：
- 闪退：usePinOcrSelect 原有 `window blur → exitMode`；独立 pin-ocr 窗创建时 focus:true 抢焦点→贴图窗 blur→退出文字模式→弹窗隐藏；且点按钮也会 blur 消失。已移除该 blur 监听（文字模式改由 Esc/再按 Alt/关闭按钮退出），新建窗口改 focus:false。
- 位置乱跳：原 PinOcrWindow 每帧按贴图位置左右翻转，且 PinWindow 按尺寸 fits 在窗内停靠/独立窗之间切换导致跳变。改为【始终】在独立 pin-ocr 窗（贴图外侧），打开时按可用空间锁定右侧/左侧，之后拖拽只跟随不翻转；删除 fits/winSize 与窗内停靠分支。
- 重翻翻译：翻译仅由用户点「翻译」触发；缩放/拖拽只 emitTo 推送当前 data 重定位，绝不重跑翻译。tsc 通过。

## 便签文字"发光"光晕去除（commit 33e3ef4）
主人反馈：便签文字周围有发光感，要清晰不要发光。根因：壁纸模式 `.editor` 的 `text-shadow` 用了
`0 0 6px`/`0 0 8px` 零偏移大模糊光晕（亮壁纸白光、暗壁纸黑光）+ 取色器/字号器标签 `0 0 2px` 光晕。
修复：删除这些光晕，仅保留 1px 紧实投影（rgba 0.6）保证壁纸可读性；标签改为 none。透明主题文字本无投影不受影响。
（注意：模糊毛玻璃只作用于背景 ::before 层 z-index:0，文字在 z-index>=1 上层，从未被模糊——之前"糊"实为光晕观感。）

## 回归：onCloseRequested 致贴图关不掉 (commit 2c1d27a)
- 上一版为「贴图关→关 OCR 弹窗」加了 `getCurrentWindow().onCloseRequested(...)` 全局监听，
  结果它拦截了贴图窗的关闭握手，导致右键菜单/双击/Esc 三种关闭途径全部失效(贴图关不掉)。
- 教训：Tauri v2 中 `onCloseRequested` 会介入窗口关闭生命周期，非必要不要挂全局关闭监听。
- 修复：移除该监听；改为在 menu close / Esc·Delete / 双击关闭三处显式调用 `closePinOcrWindow()` 销毁弹窗，
  既不拦截关闭、又能保证关闭贴图时清掉 OCR 弹窗。保留 `onResized`(仅文字模式推几何，安全)。

## OCR 弹窗孤儿窗问题 (commit 83dde1f)
- 现象：贴图关掉后 OCR 弹窗没自动关，且手动关(Esc/关闭按钮)也失效。
- 根因：弹窗的关闭事件发回【来源贴图窗】处理；来源关掉后变孤儿窗，手动关自然失效；
  而来源关闭时若某些途径没调用 closePinOcrWindow()，弹窗就残留 orphan。
- 修复(PinOcrWindow.tsx)：新增 selfClose()=emit('close')+本窗 destroy() 自身，Esc 与关闭按钮改用它；
  再加 300ms 心跳：WebviewWindow.getByLabel(来源label) 为 null 即 destroy 自身，兜底任意关闭途径。
- 教训：跨窗关闭不要单向依赖来源窗；子窗必须能自己销毁自己。PinWindow 三处 closePinOcrWindow() 保留作即时销毁。
