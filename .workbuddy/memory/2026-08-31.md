# 2026-08-31 工作日志

## 贴图 OCR 弹窗修复（commit 96798e3）
主人反馈三问题：①弹窗在外部时按完 Alt 闪一下就消失；②位置会乱跳/切换；③应放外面且贴图缩放切换位置不应再调翻译接口。
根因与修复：
- 闪退：usePinOcrSelect 原有 `window blur → exitMode`；独立 pin-ocr 窗创建时 focus:true 抢焦点→贴图窗 blur→退出文字模式→弹窗隐藏；且点按钮也会 blur 消失。已移除该 blur 监听（文字模式改由 Esc/再按 Alt/关闭按钮退出），新建窗口改 focus:false。
- 位置乱跳：原 PinOcrWindow 每帧按贴图位置左右翻转，且 PinWindow 按尺寸 fits 在窗内停靠/独立窗之间切换导致跳变。改为【始终】在独立 pin-ocr 窗（贴图外侧），打开时按可用空间锁定右侧/左侧，之后拖拽只跟随不翻转；删除 fits/winSize 与窗内停靠分支。
- 重翻翻译：翻译仅由用户点「翻译」触发；缩放/拖拽只 emitTo 推送当前 data 重定位，绝不重跑翻译。tsc 通过。
